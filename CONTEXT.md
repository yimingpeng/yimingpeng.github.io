# Portfolio Publishing

This context defines the language used for long-form writing published through Yiming's portfolio.

## Language

**Writing**:
The public area that contains Yiming's long-form technical and reflective work.
_Avoid_: Blog area, posts page

**Article**:
A single long-form work prepared for public readers and owned by Yiming.
_Avoid_: Blog post, post

**Source Article**:
The private, editable version of an Article before publication.
_Avoid_: Public draft, repository draft

**Draft**:
A Source Article that is still being shaped or reviewed and is not publicly visible.
_Avoid_: Unpublished snapshot

**Published Snapshot**:
The reviewed public version of a Source Article captured for publication.
_Avoid_: Source Article, live draft

**Series**:
An ordered group of Articles connected by one central thesis.
_Avoid_: Category, tag

**Canonical Article**:
The authoritative public copy of an Article that secondary copies identify as the original.
_Avoid_: Primary post

**Cross-post**:
A secondary public copy of an Article that points back to the Canonical Article.
_Avoid_: Duplicate original, canonical copy
