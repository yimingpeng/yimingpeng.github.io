# Own canonical writing on the portfolio

Articles are authored privately in Obsidian, exported as reviewed Markdown snapshots into the Astro
repository, and published first on the portfolio. Medium receives a manual cross-post only after the
portfolio URL is live, with that URL set as canonical. This keeps drafts private, makes every public
build reproducible from Git, preserves ownership of article URLs, and accepts an explicit export and
Medium-import step instead of introducing private-vault access into CI.
